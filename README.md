Proyecto: Desarrollo de aplicación de acceso a datos
Objetivo
Desarrollar una aplicación completa que gestione datos mediante acceso a bases de datos, aplicando técnicas avanzadas de persistencia, consultas complejas y organización del código.


Descripción del proyecto
Deberás realizar un trabajo práctico en el que desarrolles una aplicación que interactúe con una base de datos de forma estructurada y eficiente.
El proyecto consistirá en:
Diseñar una base de datos relacional completa
Implementar una aplicación conectada a la base de datos
Gestionar datos mediante operaciones CRUD avanzadas
Utilizar consultas complejas
Organizar el código en capas (acceso a datos, lógica, etc.)
Documentar todo el proceso
La idea sería hacer un menú dónde el usuario pudiera elegir la función que quiera. Una vez ahí, la aplicación se debe comunicar con la base de datos para cualquiera de las acciones.

Ejemplo orientativo:
Aplicación de gestión de:
Biblioteca (libros, préstamos, usuarios)
Tienda online (productos, clientes, pedidos)
Sistema académico (alumnos, cursos, matrículas)


Requisitos
1. Diseño de la base de datos
Crear una base de datos relacional
Definir al menos 4 o más tablas relacionadas
Uso de claves primarias y foráneas


2. Conexión y acceso a datos
Conexión a la base de datos
Uso de clases específicas para el acceso a datos (DAO)
Separación de la lógica de negocio y acceso a datos


3. Operaciones CRUD avanzadas
Implementar:
Inserción de datos con validación
Consulta de datos con filtros
Modificación de registros
Eliminación controlada


4. Consultas avanzadas
Uso de JOINs
Consultas con condiciones (WHERE, ORDER BY, GROUP BY)


5. Gestión desde la aplicación
Menú funcional (consola o interfaz gráfica)
Navegación entre opciones
Control de errores básico
Validación de entradas


6. Funcionalidad adicional
Implementar al menos una de las siguientes:
Búsqueda avanzada (filtros combinados)
Informes o listados (por ejemplo, top ventas, registros ordenados)
Importación/exportación de datos


7. Organización del código
Separación en capas:
Acceso a datos (DAO)
Lógica de aplicación
Código limpio y estructurado


8. Pruebas de funcionamiento
Verificar todas las operaciones CRUD
Probar consultas complejas
Validar comportamiento ante errores


9. Documentación práctica
Capturas de la base de datos
Explicación del diseño
Explicación del código principal
Ejemplos de uso de la aplicación


Entregables
Proyecto completo (código fuente)
Base de datos (script SQL o archivo)
Documento en PDF o Word que incluya:
Diseño de la base de datos
Explicación del funcionamiento
Capturas
Pruebas realizadas
